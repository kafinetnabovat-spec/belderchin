# حریم خصوصی در بلدرچین

آخرین به‌روزرسانی: ۱۴۰۵/۰۷/۰۲ (2026-09-24)

## خلاصه

- بلدرچین **هیچ سروری** ندارد که داده‌های شما به آن فرستاده شود.
- **هیچ** آمار، تحلیل (Analytics)، گزارش خطا (Crash Report)، تبلیغ، حساب کاربری یا شناسهٔ کاربری وجود ندارد.
- لاگ‌ها فقط روی دستگاه شما ذخیره می‌شوند و فقط وقتی خودتان بخواهید (دکمهٔ «کپی لاگ») از برنامه خارج می‌شوند؛ آدرس‌ها و توکن‌ها در آن ماسک می‌شوند.
- کد منبع کامل برنامه عمومی است و هر ریلیز به‌طور خودکار از همین کد ساخته می‌شود.

## برنامه به کجاها وصل می‌شود؟

برای این‌که بتواند کار کند، بلدرچین به این مقصدها درخواست می‌فرستد:

| مقصد | چرا | چه چیزی فرستاده می‌شود |
|---|---|---|
| Cloudflare (WARP و Workers) | برقراری خود تونل | ترافیک اینترنت شما داخل تونل رمزشده؛ برای WARP یک ثبت‌نام ناشناس یک‌باره (کلید عمومی تولیدشده روی دستگاه) |
| آینه‌های فهرست منابع (`raw.githubusercontent.com`، `belderchin.pages.dev`، `cdn.jsdelivr.net` و در صورت تنظیم، آینهٔ دلخواه شما) — فقط هنگام اتصال و حداکثر هر ۶ ساعت | دریافت فهرست امضاشدهٔ منابع اتصال (جزئیات: [SOURCES.fa.md](SOURCES.fa.md)) | یک درخواست GET ساده بدون شناسه |
| مقصدهای بررسی سلامت (`cp.cloudflare.com`, `connectivitycheck.gstatic.com`, `www.msftconnecttest.com`, `detectportal.firefox.com`) | تأیید این‌که اتصال واقعاً کار می‌کند | یک درخواست HTTP کوچک از داخل تونل |
| هستهٔ sing-box: NTP و rule-setهای هیدیفای (`raw.githubusercontent.com/hiddify/hiddify-geo`) | همگام‌سازی زمان و قوانین مسیریابی ایران | درخواست‌های استاندارد بدون شناسه |
| GitHub Releases (فقط با کلیک شما در صفحهٔ «درباره») | بررسی دستی نسخهٔ جدید | یک درخواست GET |

**نکتهٔ مهم:** ارائه‌دهندهٔ زیرساخت (Cloudflare) مانند هر ارائه‌دهندهٔ VPN دیگری می‌تواند فراداده‌های اتصال شما (مثل IP و زمان و حجم) را ببیند. بلدرچین این را پنهان نمی‌کند و در اولین اجرا به شما می‌گوید.

## چه چیزی روی دستگاه ذخیره می‌شود؟

- کلید WARP و تنظیمات اتصال (فقط روی همین دستگاه).
- فهرست منابع (نسخهٔ دریافت‌شده و نسخهٔ آفلاین).
- کش نتایج اسکن (کدام آدرس/پورت سریع‌تر بوده).
- لاگ‌های محلی برنامه و هسته.

با حذف برنامه، همهٔ این‌ها پاک می‌شوند.

## مجوزهای اندروید و دلیل آن‌ها

- **VPN**: برای ساختن تونل.
- **اینترنت**: بدیهی است.
- **اعلان‌ها / سرویس پیش‌زمینه**: تا سیستم اتصال را در پس‌زمینه نبندد.
- **اجرا بعد از بوت**: اگر «همیشه روشن» را انتخاب کرده باشید.
- **نادیده‌گرفتن بهینه‌سازی باتری** (اختیاری): فقط با درخواست خودتان و برای پایداری اتصال.
- **فهرست برنامه‌های نصب‌شده** (اختیاری): فقط اگر بخواهید برخی برنامه‌ها از تونل خارج شوند.
